# BANKNIFTY data preparation before larger training

Run the existing local QuantLab workstation, then execute:

`python -m scripts.prepare_banknifty_data --shared-root /path/to/quantlab --years 5 --option-days 365 --context-days 365 --wings 10 --confirm-reviewed`

Review Dhan, FRED/ALFRED and Alpaca data permissions before the opt-in. Use the existing local credentials, never paste them into this command. The date range ends before today's exchange-local session, with five years meaning 1825 calendar days, not a guarantee of provider retention or observed sessions. The one-year option scope is bounded near-month expired rolling strikes ATM +/-10, not full exact-contract or historical depth data. The global archive scope defaults to 365 days; it can be extended to 1825 with explicit parameters. FRED availability follows conservative vintage date plus one day at noon UTC; Alpaca uses US-listed ETF proxies and its existing conservative archive timing, not exact global index or futures levels. No guessed publication timestamps. Current source entitlements and gaps are reported. No change to feed configuration or live orders.

The acquisition submits to the running local workstation's existing job queue, uses original raw IDX_I receipts in place (new research loader verifies exact current resolved identity), resumes matching dated equity batches and reuses verified rolling option receipt windows. One bounded pass only: no infinite retry; stops submitting new tasks during the weekday 08:30-16:00 IST priority window. Cancels only its own cancellable job at market transition, or leaves a submitted noncancellable job to finish. Do not run multiple copies or parallel manual history downloads. Other automatic jobs may cause a pause; rerun after those finish. Ctrl-C stops the command's polling, not necessarily the already submitted server job. No recorder restart, model training, deletion or duplicate price store. JSON report is updated after stages. Coverage is checked from actual distinct observed regular-session minute starts and SHA/row-count verified original receipts; checked ranges alone are not continuous history. Each index gets one attempt per planned missing window, with a bounded request budget. A source failure may leave gaps; don't keep retrying an unavailable source. The stock audit verifies original equity receipts and reports member-session gaps, not automatic repair of every partially observed candle. The option-field audit samples recent 90 index sessions and ATM +/-3; wider requested options remain separately receipt-audited. Use --audit-only for a no-download review. The latest model only consumes up to 400 days; larger history needs later bounded loader/training extensions.

Unavailable sources require documented authorized historical constituent membership beyond the current reconstruction, dated official/reviewed weight files, exact expired futures contracts and their authorized price histories, publication-dated participant reports, licensed external intraday mappings and historical recorded quote/depth archives. No source evidence is manufactured, and a report marked acquisition_attempt_complete_review_gaps is NOT full data readiness. Feed and archive data still need feature integration and chronological coverage checks before neural training.
